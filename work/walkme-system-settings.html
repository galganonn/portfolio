WalkMe System’s Settings

Streamlined the settings menu to improve navigation, enabling users to find features faster

Project Overview

As our product evolved, new features were continuously added to the settings menu without a structured organization. This led to a cluttered and inefficient navigation system, making it difficult for users to find what they needed. To address this, I led a redesign to streamline the settings navigation and usability.

Why redesign the current Setting page?

Business goal

Moving all system operations to the console required a single area to manage all settings.

Fixing navigation issues

Establish a clear user flow and an intuitive experience.

What is not working today?

I gathered feedback from a range of users who had trouble locating certain settings. The primary pain points identified were:

Lack of visibility

Important settings were hidden within subcategories, making them difficult to access.

Cumbersome navigation

Frequent need to navigate back and forth between multiple pages to find the correct settings.

Inaccurate copy

Some settings were placed in categories that did not match users’ expectations.

User Research

Card Sorting

We conducted a Card Sorting workshop to map users’ mental models and intuitively restructure the navigation.

After understanding how users perceive information, we created an information architecture that reflects the new navigation structure.

Main Screens

01

Side Menu

Rearranging and adding categories

Before

In the previous menu structure, a limited number of categories resulted in new features being added inconsistently over time, leading to navigation challenges and misalignment with user expectations.

After

The redesigned menu introduces a more structured categorization, ensuring logical grouping of features that enhance discoverability and streamline the user experience.

02

Dropdowns to Tab Navigation Transformation

From Hidden to Visible

Before

The previous design relied on dropdown menus that obscured important components, requiring multiple clicks and hampering both visibility and accessibility.

After

Our redesign replaced these dropdowns with a tab menu, implementing a flat information hierarchy that displays options at a glance. This transformation significantly reduced the number of clicks needed, enhanced information scannability, and provided immediate visibility of available options, ultimately creating a more efficient and user-friendly experience.

03

Eliminating Hidden Elements

From Hidden to Visible

Before

The previous design required users to scroll within dropdown components, hiding crucial elements and creating a cumbersome navigation experience.

After

The redesign reorganized the navigation menu and eliminated scrolling, making all components instantly visible. This new structure promotes better hierarchy and reduces cognitive load.

04

Helping Users Create a Refined Interface

Design Tips for Users’ Pain Points

We identified that many users struggle with understanding the best practices for setting up their internal interface. To support them, we introduced a new screen with practical design tips—covering aspects like optimal logo format, size, and color matching—ensuring a professional and cohesive look for every user.

Key Takeaways from the Process

Users appreciate being involved

Engaging users in decision-making and seeking their input fosters trust and increases satisfaction.

User buy-in leads to better outcomes

Understanding users’ mental models and aligning the design with their expectations results in a more effective and well-received solution.
